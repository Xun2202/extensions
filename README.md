# Xun2202 Mihon extension repo (overlay)

Add to Mihon 0.20.1+ (Settings → Browse → Extension store → Add):

```
https://github.com/Xun2202/extensions/raw/repo/index.pb
```

This repo is an **overlay** on top of the official [Keiyoushi](https://github.com/keiyoushi/extensions) repo:
it only contains a few extensions that are fixed locally or that Keiyoushi no longer ships. Keep Keiyoushi
as your main repo and install only these from here.

Built automatically from [Xun2202/extensions-source](https://github.com/Xun2202/extensions-source)
(see `OVERLAY.md` there for the module list and maintenance notes). APKs are attached to GitHub Releases.
